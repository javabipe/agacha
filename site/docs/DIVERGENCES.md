# Referência × app

A regra do prompt: onde a referência e o app discordam, o app vence.

| Item na referência | Situação no app | Decisão para o site |
|---|---|---|
| macOS, Windows, web app, Apple TV com "disponível" | Não existem | Removidos. Ficam iPhone/iPad ("em breve", sem build) e "TV pelo navegador" (existe). |
| "Disponível" para iOS | Sem build publicada | "Em breve", sem botão de loja falso. |
| Tia Lu, Vovô Chico, Robô Zum, Pirata Pepa, Juíza Jô, Noel | Só Tia e Tio | Seção vira "Tia ou Tio comandam", com os avatares reais. |
| Preços R$ 0 / 29,90 / 399/ano, Pacote Família, escola | Não há compras nem preços definidos | Seção de preços sai; no lugar, "grátis de começo / preço a definir" só se você confirmar. |
| Níveis Tranquilo/Sapeca/Furacão | Iguais | Mantidos. |
| "Replay de 0,8 s" | Replay ~4 s do erro, com "Foi injusto!" | Texto corrigido. |
| "Nada gravado" | Replay do erro em vídeo temporário e Momentos salvos só no aparelho | Texto honesto: "nada sai do aparelho", sem "nada gravado". |
| Etiqueta "Dados não coletados" | Voz/fala pode ir à Apple; etiqueta em reavaliação | Não prometer a etiqueta; dizer "a câmera nunca sai do aparelho". |
| "Funciona em modo avião" | Verdade para a câmera/jogo; o reconhecimento de nomes pode usar a Apple e a TV usa Wi-Fi | "Sem conta, sem anúncios"; sem a promessa de modo avião. |
| Modos Copa da Família, conquistas, Turma, relatório PDF, Compartilhamento familiar | Não existem | Removidos. Entram: modo Pontuação (moedas/combo), Eliminação, Solo, Momentos, TV. |

| Inglês (/en) | App só em pt-BR | /en vira fase posterior, só se o app tiver inglês. |
