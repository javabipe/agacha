# Referência visual aprovada

`agacha-landing.html` é um mock publicado como artefato do claude.ai: o conteúdo começa direto no `<title>`/`<style>` (o esqueleto `<!doctype html><html><head><body>` é adicionado na publicação). Para abrir localmente, envolva o conteúdo num esqueleto HTML com `<meta charset="utf-8">` e `<meta name="viewport" content="width=device-width, initial-scale=1">`.

Não copie o arquivo para o site: reimplemente a UI em componentes Astro, preservando tokens, tipografia, hero cinético, botões "clay", seções e comportamento (tema claro/escuro, PT/EN, reveal por scroll, loop VIVO/MORTO com gesto contrário a cada 3 comandos, CTA fixo no mobile).
